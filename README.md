## 🚀 Features

### 🛡️ Combat Suite
- **Adaptive Auto Parry**: Real-Time Physics distance & velocity calculation with ping compensation.
- **Auto Speed Spam**: Instant anti-clash trigger at extreme speeds ($ge 250$ studs/s or point-blank $le 18$ studs).
- **Anti-Ball Stall & Curve Lead**: Curve compensation with custom lead offsets (+42ms for heavy curve balls).
- **Lag Ball (Hotkey V)**: Freeze/stutter the ball upon hit to disrupt opponent parry timing.
- **Troll Curves & Clash Cadence**: Customizable clash timing and manual spam (Hotkey E).
